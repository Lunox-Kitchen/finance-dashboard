MY FINANCE — PWA INSTALLATION

1. Replace your website files with all files in this folder.
2. Push to GitHub Pages.
3. On iPhone, open the GitHub Pages URL in Safari.
4. Tap Share.
5. Tap Add to Home Screen.
6. Keep "Open as Web App" enabled if iOS shows that option.
7. Tap Add.

The Home Screen app uses the same Supabase backend as the website.
Changes from laptop/phone remain synchronized.
